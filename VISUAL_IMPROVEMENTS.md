###Further UX/UI improvements

- Adding loading indicators during API requests would make the interface feel more responsive and avoid the impression that nothing is happening.
- Showing small success messages after creating, updating, or deleting a book would confirm that the action worked.
- Better and consistent colors, spacin, sizing and form design.
- Improve mobile usability with larger tap targets, sticky action areas where useful, and responsive spacing for dense forms/lists.
- The analytics page currently shows numbers only. Adding simple charts (for example, rating distribution or books per author) would make the data easier to understand.
- Supporting additional sorting options (for example by rating, date added, or author)
- Using state management to store the books collection and handling pagination on the frontend would improve performance, reduce API calls, and make the interface feel faster and more responsive.
